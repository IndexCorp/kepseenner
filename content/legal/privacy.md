# Политика конфиденциальности

**Правообладатель приложения «Кэпсээннэр»: Адамов И.Р., применяющий специальный налоговый режим «Налог на профессиональный доход» (НПД), ИНН 141002698662**

**Контакт для обращений: uluslife@mail.ru (с пометкой «приложение Кэпсээннэр»)**

**Дата вступления в силу: 11.09.2026**

Настоящая Политика конфиденциальности (далее — Политика) описывает, какие данные обрабатываются при использовании мобильного приложения «Кэпсээннэр» (далее — Приложение), и применяется ко всем его версиям. Установка Приложения и начало его использования означают согласие пользователя с Политикой. Если пользователь не согласен с Политикой, ему следует прекратить использование Приложения.

## 1. Какие данные обрабатываются

Приложение **не собирает, не хранит и не передаёт персональные данные** пользователей. Приложение не запрашивает имя, адрес электронной почты, номер телефона и иные сведения о личности, не использует регистрацию, аккаунты, аналитические и рекламные сервисы, не применяет идентификаторы устройства и не отслеживает действия пользователя.

## 2. Данные, хранящиеся на устройстве

При работе Приложения на устройстве пользователя хранятся исключительно технические данные, не позволяющие идентифицировать пользователя:

- кэш литературных произведений и их метаданных (название, автор, жанр, категория), полученных из открытого источника;
- отметки «прочитано»;
- кэш информационных и рекламных материалов.

Эти данные не покидают устройство (за исключением ситуации, когда стандартное резервное копирование Android включено пользователем на уровне системы и переносит данные Приложения в облачную резервную копию учётной записи самого пользователя). Все перечисленные данные удаляются при удалении Приложения штатными средствами устройства.

## 3. Сетевая активность

При запуске и обновлении Приложение обращается по протоколу HTTPS к открытому хранилищу контента на GitHub (raw.githubusercontent.com) за литературными произведениями, их метаданными и информационными материалами. Запросы Приложения не содержат сведений о пользователе. Другие серверы Приложением не используются.

При обращении к хранилищу контента сервисы GitHub автоматически получают технические сведения, обычно передаваемые при HTTP-запросе (в том числе IP-адрес). Их обработка осуществляется GitHub в соответствии с собственной политикой конфиденциальности и находится вне контроля правообладателя Приложения.

## 4. Внешние ссылки, реклама

Приложение может показывать информационные и рекламные блоки, включая платную рекламу. Рекламные блоки сопровождаются пометкой «реклама». Рекламные материалы передаются Приложению из хранилища контента правообладателя: Приложение не передаёт рекламным сетям и рекламодателям какие-либо данные пользователя, не формирует профиль пользователя и не измеряет его действия внутри рекламных материалов.

Переход по ссылке из блока открывает системный браузер: Приложение не перехватывает, не отслеживает и не изменяет действия пользователя на внешних ресурсах. Ответственность за содержание рекламных и информационных материалов и внешних ресурсов несут их владельцы.

## 5. Права пользователя

Пользователь вправе в любой момент:

- удалить все данные, обрабатываемые Приложением, удалив Приложение штатными средствами устройства;
- отказаться от использования Приложения;
- обратиться с вопросом об обработке данных по адресу uluslife@mail.ru (с пометкой «приложение Кэпсээннэр») и получить ответ в разумный срок.

## 6. Изменения Политики

Правообладатель вправе изменять Политику. Актуальная редакция публикуется по адресу настоящего документа и (или) в самом Приложении. Продолжение использования Приложения после публикации изменений означает согласие пользователя с новой редакцией.

## 7. Применимое право

К настоящей Политике и отношениям между правообладателем и пользователем применяется право Российской Федерации.
